# Test_task

Проект содержит:
- README.md (этот файл) 
- скрипт на Python, который применяет POSIX-права к файлам и папкам, указанным в конфигурационном файле. Работает как systemd сервис
- systemd service файл, который запускается при актовном сетевом подключении и направляет вывод, сообщения об ошибках в journald (можно посмотреть через journalctl)
- пример конфигурационного файла config.ini
